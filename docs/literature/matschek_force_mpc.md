# Matschek 等：Safe Machine-Learning-supported Model Predictive Force and Motion Control

核对日期：2026-11-10。论文：[arXiv 2303.04569v1](https://arxiv.org/abs/2303.04569v1)。已读全文 §I–VII 和附录 I–II；文末参考文献未逐篇阅读。

## 逐节与机制

§II–III 将已知机器人动力学与未知静态输出映射分开；输出包含位置和接触力。§IV 用物理力模型加 GP 残差。§V 以 GP 不确定性收紧输出约束，并在标准 MPC 可行性、平滑性及误差界假设下讨论安全性。§VI 用 KUKA 在柔性表面书写，路径进度本身是决策变量，可在线改变速度。比较线性弹簧、非线性接触及 GP 混合模型；报告力预测/控制误差、约束违规和计算时间。附录给三关节动力学、外力补偿、150 ms 预测和 10 ms 控制周期。

误差只在静态输出力映射建模；不确定性无需通过未知动力学传播。85 个 GP 训练点来自 20,000 点采集集。实机使用腕部 F/T 和关节传感器，不依赖视觉策略。

## 能借用与不能照搬

这是“学习力 + 不确定性收紧 + 机器人 MPC”的直接先例，不能声称此前只处理抽象成本。可借用将已知机器人/传感器结构与未知接触分开、同时报告预测误差和实际约束效果的实验逻辑。

它的静态弹性表面不具有切割损伤历史；把它的 force(q) 用于再进入已损伤材料会丢状态。假设 GP 误差界有效并不等于在任意新材料或策略下自动安全；单输出置信区间也不能直接等同全部时刻多分量联合力限。
